▤ База лидов

Скор 0–100 = «насколько этому бизнесу нужен сайт». hot >60 — нужен срочно (сайта нет / не открывается / не адаптивный). warm 40–60 — нужен, но не горит. cold <40 — у него уже всё хорошо или это не клиент (сеть, конкурент-студия). Наведи на цифру в карточке — покажет, из чего сложился скор.
Сайты уже собранных лидов, которые ещё не проверялись: открывается ли, https, адаптив, скорость. Сначала — у кого есть телефон. Остановить — круглой кнопкой.
Экспорт текущей вкладки
Выгрузка — только с согласия руководителя: он получит запрос и нажмёт «Разрешить», файл скачается сам. Одно согласие — один файл.
Импорт своего JSON
Подойдёт файл-экспорт этого приложения или любой JSON-массив объектов с полями name, phone, website, city, address, industry, email, socials… (или обёртка {"leads":[…]}). Дубли склеиваются с базой, скор считается сам.
База и корзина общие и хранятся на сервере: из окна их не стереть. Удалённого лида можно вернуть из корзины.
