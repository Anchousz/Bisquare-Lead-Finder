# Bisquare Lead Finder

Десктопное приложение для менеджеров веб-студии: собирает компании из нескольких источников, оценивает по шкале от 0 до 100, нужен ли им сайт, и помогает вести базу лидов.

Проект студии [Bisquare](https://bisquare.ru).

> **В репозитории только клиентская часть.** Приложение работает по клиент-серверной схеме. Для запуска требуется сервер с базой данных и панелью управления (PHP), который не входит в этот репозиторий. Код выложен для ознакомления с архитектурой и клиентской логикой.

## Что умеет

- **Сбор лидов** из 2ГИС, Яндекс.Карт, ВКонтакте и OpenStreetMap. Дубли склеиваются по телефону, домену, названию и городу.
- **Оценка «нужен ли сайт»**: проверка доступности, HTTPS, адаптивности и скорости (через Playwright или Google PageSpeed). Присвоение статусов hot / warm / cold.
- **Работа с базой**: фильтры по статусу, контактам и оценке, избранное, отметки, корзина с восстановлением, карточка лида с расшифровкой оценки.
- **Календарь и CRM** внутри приложения: бронь по договорённости с лидом и смета.
- **Импорт** своих данных из JSON.
- **Экспорт в JSON и CSV** только с согласия владельца (запрос приходит ему в Telegram и в панель управления).

## Архитектура и защита данных

- **Клиент (Electron + Python)**: интерфейс на Electron, локальный HTTP-сервер на Python (только стандартная библиотека) для обработки логики и сбора данных.
- **Сервер (PHP)**: единая база данных, ключи API и панель управления.
- Ключи API хранятся только на сервере, в клиентское приложение они не попадают.
- База общая и лежит на сервере, на компьютере менеджера остаётся только кеш в памяти.
- Доступ можно приостановить или отозвать из панели.
- Бэкенд (Python) принимает локальные запросы только с одноразовым токеном, который генерируется Electron при каждом запуске.

## Стек

- **Клиент**: Electron, Python 3.12 (ядро на стандартной библиотеке), JavaScript без фреймворков, NSIS-установщик.
- **Сервер** (вне репозитория): PHP, MySQL.

## Структура

```
electron-main.js   окно приложения, запуск и остановка бэкенда
server.py          локальный HTTP-сервер и API для интерфейса
leadfinder.py      сбор лидов, бюджет запросов, оценка сайтов
sources.py         источники: OSM, Яндекс.Карты, ВКонтакте
store.py           база лидов, дедупликация, экспорт
cloud.py           связь с сервером: вход, синхронизация, проксирование
web/               интерфейс (HTML, CSS, JS)
```

## Запуск в разработке

1. Установите зависимости:

```bash
   npm install
```

2. Задайте адрес сервера через переменную окружения `BISQUARE_SERVER`:

   - Windows (PowerShell): `$env:BISQUARE_SERVER="https://your-server.example.com"`
   - macOS/Linux: `export BISQUARE_SERVER="https://your-server.example.com"`

3. Запустите приложение:

```bash
   npm start
```

*(Сборка установщика: `npm run dist`)*

## Ответственное использование

Приложение работает с публичными данными организаций и с API сторонних сервисов. Перед использованием убедитесь, что у вас есть право работать с выбранными источниками: у 2ГИС и Яндекс.Карт действуют собственные условия использования API (в том числе о хранении и массовой выгрузке данных), а контактные данные организаций могут подпадать под законодательство о персональных данных (152-ФЗ) и о рекламе. Ответственность за соблюдение этих условий лежит на пользователе приложения.
